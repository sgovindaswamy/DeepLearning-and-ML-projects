# Deep Learning and ML Projects

This repository is a collection of applied machine learning and deep learning projects covering time series forecasting, tabular classification, NLP, predictive maintenance, and computer vision. The projects are designed to showcase practical workflows from data loading and preprocessing to model training, evaluation, and interpretation.

## Repository Overview

The projects in this workspace demonstrate a broad range of modern ML techniques and technologies, including:

- time-series forecasting with ARIMA, SARIMA, Exponential Smoothing, and LSTM
- statistical analysis and business intelligence with e-commerce sales data
- transfer learning for text classification with FastAI and AWD-LSTM
- predictive maintenance using anomaly detection and supervised classification
- semantic segmentation of aerial imagery using U-Net

---

## Project Portfolio

### 1) Amazon Stock Price Prediction

Focus: financial forecasting and time-series modeling

Technologies:
- Python
- pandas
- matplotlib/seaborn
- statsmodels
- scikit-learn
- TensorFlow/Keras
- LSTM neural networks

This project compares classical forecasting models with an LSTM to predict Amazon stock prices over time.

### 2) Ecommerce Sales Data Analysis

Focus: exploratory data analysis and business intelligence

Technologies:
- pandas
- matplotlib
- seaborn
- statsmodels
- OLS regression
- data visualization

This project analyzes category performance, pricing effects, monthly sales trends, and customer satisfaction using retail sales data.

### 3) Natural Language Processing for Job Description Classification

Focus: text classification and transfer learning

Technologies:
- Python
- pandas
- FastAI
- AWD-LSTM
- NLP preprocessing
- text classification pipelines

This project uses ULMFiT-style transfer learning to classify job descriptions into categories using domain-specific text modeling.

### 4) Predictive Maintenance Dataset

Focus: anomaly detection and failure prediction

Technologies:
- pandas
- scikit-learn
- PCA
- Isolation Forest
- One-Class SVM
- Local Outlier Factor
- Random Forest
- Autoencoders
- Dash/Plotly

This project analyzes industrial machine data for predictive maintenance and compares traditional anomaly detection with supervised classification methods.

### 5) Semantic Segmentation of Aerial Imagery

Focus: pixel-wise classification and computer vision

Technologies:
- Python
- OpenCV
- NumPy
- TensorFlow/Keras
- U-Net
- patch-based image processing
- segmentation models

This project trains a U-Net model to segment aerial images into semantic classes and evaluate performance using mean IoU.
