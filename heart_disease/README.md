## Heart Disease Prediction

Raw UCI Machine Learning Repository "Heart Disease" dataset (`Dataset/`), combining four databases — Cleveland, Hungarian, VA Long Beach, and Switzerland — used for predicting the presence of heart disease from patient attributes. Official source: https://archive.ics.uci.edu/dataset/45/heart+disease

Each database shares the same 76 raw attributes, with a commonly used 14-attribute subset (see `processed.*.data` files). Analysis notebook pending.
