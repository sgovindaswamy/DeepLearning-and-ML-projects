# Project Dashboard

This dashboard links the major ML and DL projects in this repository and the main tasks each one addresses.

## Overview

| Project | Folder | Domain | Main Technique | Output |
| --- | --- | --- | --- | --- |
| Amazon Stock Price Prediction | [Amazon_stock_price_prediction](Amazon_stock_price_prediction) | Finance | ARIMA, SARIMA, Exponential Smoothing, LSTM | Time-series forecast |
| Ecommerce Sales Data Analysis | [ecommerce_sales_data_analysis](ecommerce_sales_data_analysis) | Retail analytics | EDA, OLS regression | Business insights |
| Natural Language Processing for Job Description Classification | [Natural_language_processing_job_description](Natural_language_processing_job_description) | NLP / HR | AWD-LSTM + transfer learning | Job category classification |
| Predictive Maintenance Dataset | [Predictive_maintenance_dataset](Predictive_maintenance_dataset) | Industry / IoT | Anomaly detection + Random Forest + Autoencoder | Failure prediction |
| Semantic Segmentation of Aerial Imagery | [semantic_segmentation_of_aerial_imagery](semantic_segmentation_of_aerial_imagery) | Computer vision | U-Net | Pixel-wise segmentation |

## Run Order

1. Start with the EDA-heavy projects for data understanding.
2. Move to machine learning and deep learning notebooks.
3. Use the deployment example only after you understand the model logic.

## Notes

- Some projects rely on external datasets from Kaggle or UCI.
- Environment requirements differ slightly by project.
- The repository is intended as a research and portfolio showcase rather than a single production pipeline.
